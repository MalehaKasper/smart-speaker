# 🎛 Smart Speaker 2.1 EQ — мобільний додаток

**Розумний пульт керування та обчислювальний центр рум-корекції (Flutter, Dart).**

Керує колонкою [smart-speaker-firmware](https://github.com/MalehaKasper/smart-speaker-firmware) (ESP32) через BLE: гучність, джерело звуку, завантаження коефіцієнтів параметричного еквалайзера. Аналізує акустику кімнати мікрофоном смартфона — генерує калібрувальний сигнал (pink noise / sweep), рахує FFT прийнятого звуку, будує цільову криву й розраховує біквадратні фільтри для авто-EQ. Повна історія рішень — у `openspec/changes/`.

## 📌 Статус

- [x] Каркас проєкту (`flutter create`), залежності: `flutter_blue_plus`, `record`, `fftea`, `shared_preferences`, `permission_handler`
- [ ] BLE-клієнт: пошук/підключення за MAC/ім'ям, відправка `0x01`/`0x02`/`0x03`, підписка на notify гучності
- [ ] Захоплення звуку з мікрофона (`record`)
- [ ] Auto-EQ: генерація калібрувального сигналу, FFT-аналіз, побудова цільової кривої
- [ ] Калькулятор біквадратних коефіцієнтів → сирий байтовий payload (`0x03`)
- [ ] Головний екран: повзунок гучності, перемикач Bluetooth/AUX, індикація BLE-статусу
- [ ] Екран еквалайзера: інтерактивний графік АЧХ, ручні точки (Gain/Q/Frequency), кнопка авто-корекції
- [ ] Локальне збереження пресетів EQ та MAC-адреси колонки (`shared_preferences`)

## 🛠 Запуск

```bash
flutter pub get
flutter run
```

## 🧩 Архітектура (плановано)

```
lib/
├── ble/          BLE-клієнт (flutter_blue_plus): підключення, протокол 0x01/0x02/0x03
├── dsp/           FFT-аналіз, побудова цільової кривої, калькулятор biquad-коефіцієнтів
├── ui/
│   ├── home/      Гучність, джерело, статус з'єднання
│   └── eq/        Графік АЧХ, ручні точки, запуск авто рум-корекції
└── storage/       Пресети EQ та MAC-адреса колонки (shared_preferences)
```
