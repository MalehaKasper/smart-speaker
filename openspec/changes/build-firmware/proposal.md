## Why

Колонка Smart Speaker 2.1 потребує центрального менеджера на ESP32, який приймає звук по Bluetooth, керує DSP-процесором ADAU1401, обробляє фізичні органи керування та синхронізується з мобільним додатком керування й рум-корекції. Без цієї прошивки жоден з фізичних чи програмних компонентів колонки не працює разом.

## What Changes

- Прийом аудіопотоку по Bluetooth (A2DP Sink) і трансляція на ADAU1401 через I2S зі стабільним буфером без розривів
- BLE GATT-сервер: прийом гучності (`0x01`), джерела звуку (`0x02`), коефіцієнтів EQ (`0x03`) від додатка; notify зміни гучності, ініційованої фізичним енкодером
- I2C-керування ADAU1401 виключно через Safeload-регістри для гучності, джерела та EQ — без аудіо-артефактів
- Обробка роторного енкодера (обертання/натискання) на апаратних перериваннях і ІЧ-пульта через `IRremote`
- Вивід поточної гучності або джерела на екран TM1650 по I2C
- VU-метр гучності на адресній стрічці WS2812B (`FastLED`), колір виключно бурштиновий
- Збереження останньої гучності, джерела та коефіцієнтів EQ в NVS з відновленням після перезавантаження

## Capabilities

### New Capabilities
- `bluetooth-audio-pipeline`: прийом A2DP-потоку та стабільна трансляція на DSP по I2S
- `ble-control-protocol`: BLE GATT-сервер, протокол команд і сповіщень для мобільного додатка
- `dsp-safeload-control`: I2C-керування ADAU1401 через Safeload-регістри
- `encoder-ir-input`: обробка роторного енкодера та ІЧ-пульта
- `status-display`: вивід гучності/джерела на TM1650
- `led-vu-meter`: бурштиновий VU-метр гучності на WS2812B
- `settings-persistence`: збереження стану в NVS

## Impact

- Папка `firmware/` монорепозиторію `smart-speaker` (PlatformIO, ESP32-WROOM-32)
- Залежності: `FastLED`, `IRremote`, `NimBLE-Arduino`, `ESP32-A2DP`
- Протокол BLE (`0x01`/`0x02`/`0x03`) — спільний контракт з `app/`; оскільки обидві сторони живуть в одному репозиторії, зміна формату планується і мержиться одним PR разом зі стороною додатка
