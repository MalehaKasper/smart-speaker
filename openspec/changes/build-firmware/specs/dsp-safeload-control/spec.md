## ADDED Requirements

### Requirement: Керування ADAU1401 по I2C
Система SHALL керувати DSP-процесором ADAU1401 як I2C-майстер.

#### Scenario: ESP32 ініціює I2C-транзакції
- **WHEN** потрібно змінити гучність, джерело або EQ на DSP
- **THEN** ESP32 надсилає відповідні I2C-транзакції до ADAU1401

### Requirement: Запис виключно через Safeload-регістри
Будь-який запис нових коефіцієнтів еквалайзера або рівнів гучності SHALL виконуватися виключно через Safeload-регістри ADAU1401, а не прямим записом у цільові регістри.

#### Scenario: Зміна гучності без клацання
- **WHEN** система застосовує нове значення гучності
- **THEN** запис виконується через Safeload-послідовність (буфер даних → адреса цілі), а не прямим записом у цільовий регістр

#### Scenario: Зміна EQ без аудіо-артефактів
- **WHEN** система застосовує нові коефіцієнти біквадратних фільтрів
- **THEN** запис виконується через Safeload-послідовність, щоб уникнути чутних артефактів під час зміни
