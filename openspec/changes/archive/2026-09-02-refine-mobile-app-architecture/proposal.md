## Why

`build-mobile-app` дав повний план додатка, але кілька фундаментальних рішень лишились невирішеними: платформа (iOS не сумісний з припущенням "стабільна MAC-адреса"), архітектура спільного стану між екранами, де саме виконується важка FFT-математика, і — найпомітніше — специфікація описувала лише один механізм "збереження" (`local-presets-storage`), тоді як реальна потреба виявилась подвійною: автоматична історія для загальних налаштувань і окремо іменовані пресети для EQ. Без цих рішень неможливо коректно почати реалізацію.

## What Changes

- Звуження платформи до Android (iOS прибирається зі скоупу — нестабільність MAC-адреси на iOS ламає `ble-client-connection`)
- Архітектура стану на `flutter_riverpod` — спільне джерело правди для BLE-з'єднання й гучності між екранами
- Важкі обчислення (FFT) — виключно в окремому isolate, ніколи в UI-ізоляті
- Нова capability `settings-history`: автоматична, ненайменована історія для гучності/джерела (кільцевий буфер, snackbar "Скасувати")
- Звуження `local-presets-storage` до EQ: лише свідомі іменовані пресети, без автоматичної історії окремих правок смуг
- Новий UI-гап: екран пошуку/підключення до колонки (`ble-client-connection` описувала лише поведінку, не UI)
- Новий UI-елемент: список пресетів EQ на екрані еквалайзера (`equalizer-screen`)

## Capabilities

### New Capabilities
- `settings-history`: автоматична історія змін загальних налаштувань (гучність, джерело) з можливістю скасувати останню зміну

### Modified Capabilities
- `local-presets-storage`: звужується до пресетів еквалайзера — прибирається будь-яка неявна прив'язка до загальних налаштувань, додається явна відсутність автоматичної історії для EQ
- `ble-client-connection`: додається вимога до UI пошуку/підключення (список знайдених пристроїв, дія підключення)
- `equalizer-screen`: додається вимога UI списку пресетів (зберегти/обрати/видалити)

## Impact

- `app/pubspec.yaml`: додається `flutter_riverpod`; платформа звужується до Android (iOS-артефакти каркасу лишаються невикористаними, не видаляються цією зміною)
- `app/lib/`: нова структура — провайдери стану (Riverpod), окремий isolate для FFT, сховище історії (`settings-history`) окремо від сховища пресетів (`local-presets-storage`)
- Не зачіпає протокол BLE (`0x01`/`0x02`/`0x03`, 8 смуг, MTU) чи бік прошивки — суто архітектура й UI-скоуп додатка
